# 基于 STM32 和 Modbus 的直流电机 PID 调速控制系统

> 系统以 STM32F103 作为下位机，通过 Qt 上位机与下位机进行 Modbus-RTU 通信，支持电机转/停、正反转及加减速的指令下发与状态回读，并集成 OLED 显示与 EEPROM 参数存储功能，适用于智能家居、工业自动化等场景。

## 项目简介

本项目实现了一套完整的直流电机闭环调速系统，由 **STM32F103C8T6 下位机固件** 与 **Qt 上位机软件** 两部分组成，二者通过 UART 串口以 **Modbus-RTU** 协议通信。

下位机采用 **编码器测速 + 增量式 PID** 的闭环控制方案，实时调节 PWM 占空比，使电机转速快速、平稳地跟踪目标值；上位机负责指令下发、状态回读与实时速度曲线绘制。


## 功能特性

- **Modbus-RTU 通信**：支持功能码 `0x03`（读保持寄存器）与 `0x06`（写单个寄存器），带 CRC16 校验与从机地址校验
- **电机控制**：启动/停止、正转/反转、目标转速设定（0~100）
- **PID 闭环调速**：带死区补偿的增量式 PID，PWM 输出限幅，转速平稳无超调
- **编码器测速**：定时器编码器模式（TIM2/TIM3）实时采集电机转速
- **状态回读**：上位机可实时回读目标速度与当前速度，并绘制速度曲线
- **OLED 显示**：I2C 接口 OLED 实时显示运行状态与转速
- **EEPROM 参数存储**：I2C 接口 EEPROM 保存关键参数，掉电不丢失

## Modbus 寄存器说明

**从机地址**：见 `modbus.c` 中 `MODBUS_ADDR` 定义 ｜ **通信参数**：115200, 8N1

| 寄存器地址 | 名称     | 读/写     | 说明                          |
|:---------:|:--------|:---------|:------------------------------|
| 0x0000    | 目标速度 | 读 / 写   | 0~100，写入超过 100 自动钳位   |
| 0x0001    | 运行命令 | 写       | 0=停止，1=正转，2=反转         |
| 0x0001    | 当前速度 | 读       | PID 反馈的实际转速             |

**典型交互**：
- 写目标速度 60 并正转：`0x06` 写寄存器 0 = 60，`0x06` 写寄存器 1 = 1
- 读状态：`0x03` 读起始寄存器 0、数量 2，一次返回（目标速度，当前速度）

## PID 控制算法

下位机采用**带死区补偿的增量式 PID**：

```
u(k) = u(k-1) + Kp·[e(k) - e(k-1)] + Ki·e(k) + Kd·[e(k) - 2·e(k-1) + e(k-2)]
```

- PWM 输出限幅：`PWM_MIN = 0`，`PWM_MAX = 99`（TIM4 输出 10kHz PWM，ARR = 999）
- 死区补偿：克服静摩擦带来的低速控制死区
- PID 参数及调参过程详见技术文档

## 环境与编译

### 下位机（STM32）

- 硬件：STM32F103C8T6 最小系统板 + 直流减速电机（带 AB 相编码器）+ 电机驱动模块 + 0.96 寸 OLED（I2C）+ EEPROM（I2C）
- 软件：Keil MDK 5（ARM Compiler），打开 `STM32F103C8T6_MOTOR/MDK-ARM/` 下的工程文件直接编译烧录
- 如需修改引脚/外设配置，可用 STM32CubeMX 打开 `.ioc` 文件重新生成

### 上位机（Qt）

- 环境：Qt 5.9+（依赖模块：`serialport`、`charts`）
- 编译：

```bash
cd 上位机-QT/Modbus/ModbusRtu
qmake ModbusRtu.pro
make        # Windows 下可用 Qt Creator 直接打开 .pro 编译运行
```

## 使用方法

1. 烧录 STM32 固件，接好电机、编码器、OLED 与 USB 转 TTL 模块
2. 运行 Qt 上位机，选择对应串口（115200, 8N1）并连接
3. 通过界面下发目标速度与转向命令，观察 OLED 与上位机曲线中的实时转速响应
4. 演示效果见仓库根目录 `效果视频.mp4`
